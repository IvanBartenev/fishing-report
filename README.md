#  Fishing Report — Прогноз клева по атмосферному давлению

**Fishing Report** — это веб-приложение, которое помогает рыболовам выбрать идеальный день для ловли рыбы, анализируя атмосферное давление. 

Вместо того чтобы гадать, программа запрашивает прогноз погоды, рассчитывает стабильность давления по специальной формуле и выдает оценку каждого дня от 0 до 100. Идеальный день — это стабильное давление или его плавное снижение.

##  Возможности (MVP)
- **Поиск по городам:** Ввод названия города (с поддержкой синонимов, например, «Питер» → Санкт-Петербург).
- **Выбор периода:** Прогноз на 7 или 14 дней.
- **Умный скоринг:** Бизнес-логика штрафует за резкие скачки давления и аномальные отклонения от нормы, но поощряет плавное снижение.
- **Визуализация:** Интерактивный график с двумя осями (баллы и само давление в мм рт. ст.) и подсказками с объяснением оценки.
- **Кэширование:** Защита от лишних запросов к API (данные хранятся в памяти 1 час).

##  Архитектура проекта
Проект спроектирован с прицелом на дальнейшее расширение (добавление новых API, баз данных и т.д.):

- `app/providers/` — адаптеры к погодным API (реализация: Open-Meteo).
- `app/domain/` — чистая бизнес-логика (расчет баллов), не зависит от API и HTTP.
- `app/api/` (в `main.py`) — слой FastAPI, принимающий запросы.
- `app/templates/` — фронтенд (HTML + Chart.js).
- `app/cache/` — простой кэш в памяти для оптимизации запросов.
- `tests/` — юнит-тесты для бизнес-логики (Pytest).

##  Стек технологий
- **Backend:** Python, FastAPI, Uvicorn
- **Frontend:** HTML, Vanilla JS, Chart.js
- **Источник данных:** Open-Meteo API (геокодинг, прогноз, архив)
- **Тестирование:** Pytest

##  Установка и запуск (локально)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/fishing-report.git
   cd fishing-report

2. **Создайте и активируйте виртуальное окружение:**
   ```
   python -m venv venv

   Для Windows:
   venv\Scripts\activate

   Для Linux/Mac:
   source venv/bin/activate

3. **Установите зависимости:**
   ```
   pip install -r requirements.txt

4. **Запустите сервер:**
   ```
   uvicorn app.main:app --reload --port 8001

5. **Откройте браузер:**

   Перейдите по адресу http://127.0.0.1:8001
